# Agentshed

[简体中文](README.md) · [English](README.en.md) · **Français** · [Español](README.es.md) · [Русский](README.ru.md) · [日本語](README.ja.md)

**Vos coding agents, sous vos yeux.** Une application macOS qui montre, sur tous vos projets, quels skills, plugins et serveurs MCP Claude Code, Codex et d’autres coding agents ont installés, ce dont ils se souviennent et combien de tokens ils ont consommé ; elle permet de relire chaque session question par question, de rechercher ce que vous avez demandé dans toutes les sessions, et d’installer des skills de votre bibliothèque globale dans n’importe quel projet. Elle lit les fichiers que vos agents laissent sur votre Mac et n’y écrit que lorsque vous installez ou désinstallez un skill ; elle ne se connecte au réseau que pour vérifier et télécharger ses mises à jour sur GitHub Releases. macOS 12 ou ultérieur, Apple Silicon.
