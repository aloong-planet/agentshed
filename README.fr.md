# Agentshed

[简体中文](README.md) · [English](README.en.md) · **Français** · [Español](README.es.md) · [Русский](README.ru.md) · [日本語](README.ja.md)

L’atelier de vos coding agents : une vue d’ensemble de Claude Code, Codex et Grok sur tous vos projets — quels skills / plugins / MCP chaque projet possède, combien de tokens il a consommés, quels documents il a accumulés ; et l’installation / désinstallation de skills depuis la bibliothèque globale vers n’importe quel projet.

Application de bureau Electron. macOS d’abord, Windows ensuite. En cours de développement.

## Télécharger et installer

Agentshed nécessite macOS 12 ou une version ultérieure, sur un Mac Apple Silicon (puce de la série M).

1. Téléchargez le DMG depuis [le site d’Agentshed](https://agentshed.aloongplanet.com/en/) (en anglais) ou depuis [GitHub Releases](https://github.com/aloong-planet/agentshed/releases).
2. Ouvrez-le et faites glisser Agentshed dans le dossier Applications.
3. Ouvrez Agentshed depuis Applications. La première fois, macOS vous demande une seule fois d’ouvrir une app téléchargée depuis Internet, en précisant qu’Apple l’a analysée à la recherche de logiciels malveillants et n’en a trouvé aucun. Cliquez sur Ouvrir.
