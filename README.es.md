# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · **Español** · [Русский](README.ru.md) · [日本語](README.ja.md)

**Tus coding agents, a la vista.** Una aplicación para macOS que muestra, en todos tus proyectos, qué skills, plugins y servidores MCP han instalado Claude Code, Codex y otros coding agents, qué recuerdan y cuántos tokens han consumido; permite releer cada sesión pregunta por pregunta, buscar lo que preguntaste en todas ellas e instalar skills de tu biblioteca global en cualquier proyecto. Lee los archivos que tus agents dejan en tu Mac y solo escribe en ellos cuando instalas o desinstalas un skill; solo usa la red para comprobar y descargar sus actualizaciones en GitHub Releases. macOS 12 o posterior, Apple Silicon.

La descripción completa está en inglés: [README.en.md](README.en.md). Sitio web: [agentshed.aloongplanet.com](https://agentshed.aloongplanet.com). Licencia: [MIT](LICENSE).
