# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · **Español** · [Русский](README.ru.md) · [日本語](README.ja.md)

El taller de tus coding agents: una vista completa de Claude Code, Codex y Grok en todos tus proyectos — qué skills / plugins / MCP tiene cada proyecto, cuántos tokens ha consumido, qué documentos ha acumulado; y la instalación / desinstalación de skills desde la biblioteca global a cualquier proyecto.

Aplicación de escritorio Electron. Primero macOS, después Windows. En desarrollo.

## Descargar e instalar

Agentshed necesita macOS 12 o posterior en un Mac con Apple Silicon (chip de la serie M).

1. Descarga el DMG desde [el sitio web de Agentshed](https://agentshed.aloongplanet.com/en/) (en inglés) o desde [GitHub Releases](https://github.com/aloong-planet/agentshed/releases).
2. Ábrelo y arrastra Agentshed a la carpeta Aplicaciones.
3. Abre Agentshed desde Aplicaciones. La primera vez, macOS te pregunta una sola vez si quieres abrir una app descargada de Internet, e indica que Apple la ha analizado en busca de software malicioso y no ha encontrado ninguno. Haz clic en Abrir.
