# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · **日本語**

**あなたの coding agents を、一望のもとに。** すべてのプロジェクトについて、Claude Code・Codex などの coding agents がどの skills・plugins・MCP サーバーをインストールし、何を記憶し、token をどれだけ消費したかを一か所で見せる macOS アプリです。各セッションを質問ごとに読み返し、尋ねた内容をすべてのセッションから検索でき、グローバルライブラリの skill を任意のプロジェクトにインストールすることもできます。agents が Mac に残したファイルを読み取り、書き込むのは skill をインストール・アンインストールするときだけです。ネットワークを使うのは、GitHub Releases でアプリの新しいバージョンを確認・ダウンロードするときだけです。macOS 12 以降、Apple Silicon。

詳しい説明は英語版にあります：[README.en.md](README.en.md)。ウェブサイト：[agentshed.aloongplanet.com](https://agentshed.aloongplanet.com)。ライセンス：[MIT](LICENSE)。
