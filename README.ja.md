# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · **日本語**

あなたの coding agents の道具小屋:Claude Code と Codex のプロジェクト全体像 —— 各プロジェクトにどの skills / plugins / MCP が入っているか、token をどれだけ消費したか、どんなドキュメント成果物が蓄積されたか。さらにグローバルライブラリから任意のプロジェクトへ skills をインストール / アンインストールできます。

Electron デスクトップアプリ。macOS が先行、Windows は後続。開発中です。
