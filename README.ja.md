# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · **日本語**

**あなたの coding agents の道具小屋。** すべてのプロジェクトについて、Claude Code・Codex などの coding agents が何をインストールし、token をどれだけ消費し、あなたが何を尋ねたかを一か所で見せる macOS アプリです。すべてのプロジェクトのセッションを横断して検索でき、グローバルライブラリの skill を任意のプロジェクトにインストールすることもできます。agents が Mac に残したファイルを読み取り、書き込むのは skill をインストール・アンインストールするときだけです。ネットワークを使うのは、GitHub Releases でアプリの新しいバージョンを確認・ダウンロードするときだけです。macOS 12 以降、Apple Silicon。

詳しい説明は英語版にあります：[README.en.md](README.en.md)。ウェブサイト：[agentshed.aloongplanet.com](https://agentshed.aloongplanet.com)。ライセンス：[MIT](LICENSE)。
