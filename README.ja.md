# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · **日本語**

あなたの coding agents の道具小屋:Claude Code・Codex・Grok のプロジェクト全体像 —— 各プロジェクトにどの skills / plugins / MCP が入っているか、token をどれだけ消費したか、どんなドキュメント成果物が蓄積されたか。さらにグローバルライブラリから任意のプロジェクトへ skills をインストール / アンインストールできます。

Electron デスクトップアプリ。macOS が先行、Windows は後続。開発中です。

## ダウンロードとインストール

macOS 12 以降を搭載した Apple シリコン(M シリーズチップ)の Mac が必要です。

1. [Agentshed のウェブサイト](https://agentshed.aloongplanet.com/en/)(英語)または [GitHub Releases](https://github.com/aloong-planet/agentshed/releases) から DMG をダウンロードします。
2. DMG を開き、Agentshed を「アプリケーション」フォルダにドラッグします。
3. 「アプリケーション」から Agentshed を開きます。初回だけ、インターネットからダウンロードしたアプリを開くかどうかを macOS が確認し、Apple が悪質なソフトウェアがないかチェックして何も検出されなかったことも表示されます。「開く」をクリックしてください。
