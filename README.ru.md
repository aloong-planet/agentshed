# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md) · **Русский** · [日本語](README.ja.md)

**Мастерская ваших coding agents.** Приложение для macOS, которое показывает по всем проектам, какие skills, plugins и MCP-серверы установили Claude Code, Codex и другие coding agents, что они запомнили и сколько токенов израсходовали; в нём можно перечитать каждую сессию вопрос за вопросом, искать то, о чём вы спрашивали, по всем сессиям и устанавливать skills из вашей глобальной библиотеки в любой проект. Оно читает файлы, которые агенты оставляют на вашем Mac, и пишет в них, только когда вы устанавливаете или удаляете skill; в сеть оно обращается лишь для того, чтобы проверить и скачать свои обновления на GitHub Releases. macOS 12 или новее, Apple Silicon.

Полное описание — на английском: [README.en.md](README.en.md). Сайт: [agentshed.aloongplanet.com](https://agentshed.aloongplanet.com). Лицензия: [MIT](LICENSE).
