# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md) · **Русский** · [日本語](README.ja.md)

Мастерская ваших coding agents: полная картина Claude Code и Codex по всем проектам — какие skills / plugins / MCP есть у каждого проекта, сколько токенов он израсходовал, какие документы накопил; а также установка и удаление skills из глобальной библиотеки в любой проект.

Настольное приложение на Electron. Сначала macOS, затем Windows. В разработке.
