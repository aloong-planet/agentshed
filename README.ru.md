# Agentshed

[简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md) · **Русский** · [日本語](README.ja.md)

Мастерская ваших coding agents: полная картина Claude Code, Codex и Grok по всем проектам — какие skills / plugins / MCP есть у каждого проекта, сколько токенов он израсходовал, какие документы накопил; а также установка и удаление skills из глобальной библиотеки в любой проект.

Настольное приложение на Electron. Сначала macOS, затем Windows. В разработке.

## Загрузка и установка

Для Agentshed нужен Mac с Apple Silicon (чип серии M) и macOS 12 или новее.

1. Скачайте DMG с [сайта Agentshed](https://agentshed.aloongplanet.com/en/) (на английском) или со страницы [GitHub Releases](https://github.com/aloong-planet/agentshed/releases).
2. Откройте его и перетащите Agentshed в папку «Программы».
3. Откройте Agentshed из папки «Программы». При первом запуске macOS один раз спросит, открыть ли приложение, загруженное из интернета, и укажет, что Apple проверила его на вредоносное ПО и ничего не обнаружила. Нажмите «Открыть».
