## About this version

- Scrollbars are now a slim grey rounded thumb with no track. This is also the first version that arrives through the in-app update: with 0.1.0-beta installed, an update button appears at the bottom left; click it to install and restart, or let it install the next time you quit.

---

### Improved / changed

- Every scrolling area's scrollbar is a 6px rounded thumb in a neutral grey with no track, always shown when the content overflows and darker on hover. Light and dark each have their grey; the colour themes do not change it.

## Download and install

| Platform | File | Notes |
|---|---|---|
| macOS (Apple Silicon) | `Agentshed-0.1.0-beta.2-mac-arm64.dmg` | For M-series Macs, macOS 12 or later. Notarized by Apple; confirm once on first open |

First use
- macOS: notarized by Apple. Open the DMG, drag Agentshed into Applications, and open it from there. The first time, macOS asks once whether to open an app downloaded from the internet, and notes that Apple checked it for malicious software and found none. Click Open; it will not ask again. Every app downloaded in a browser gets this step; it is not a security warning. Only Apple Silicon (M-series) Macs are supported for now; Intel Macs are not (Apple menu \x{2192} About This Mac shows the chip).
- With 0.1.0-beta installed there is nothing to download by hand: the app fetches the new version in the background; click the update button at the bottom left to install and restart, or it installs the next time you quit.
