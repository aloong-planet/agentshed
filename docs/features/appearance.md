# 外观主题

## 概述
用户可在三种全 app 配色方案间切换,浅深跟随系统外观。不写入 agent 配置。

## 能力
- 设置维(rail ⚙️):外观三选一——**紫**(默认/现网)、**雾蓝**、**琥珀褐**
- 切换后立即对**整个界面**生效(列表、详情、会话、toast、浮层/抽屉、Markdown 标题与链接等跟强调色的部分)
- 浅色/深色跟随 macOS 系统外观,设置页不单独控制昼夜
- 偏好持久化,重启后保留
- 进出设置不丢当前选中的项目

## 边界与不做
- 不改变 CC/CX 侧徽标与 provider 图表品牌色
- 不写入 Claude/Codex 配置
- v1 无强制浅/深、无自定义色、无第四种方案
