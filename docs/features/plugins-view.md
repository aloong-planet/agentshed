# Plugins 视图

> 关联决策: ADR-0010

## 概述
插件可以装在用户级或只装给某个项目,包内还自带 skills、subagents、hooks、MCP 等组件——此前查看器把插件当纯全局概念且看不见包内组件,project-scope 安装会显示错。本功能按侧分组展示插件、如实呈现每条安装记录与各视角的启用状态,并可展开查看内含组件。

## 能力
- 按侧分组两组:Claude Code 组与 Codex 组,同名插件不跨侧合并
- Claude 组每行:名称、版本、启用状态、逐条安装记录(作用域与归属项目;多条记录不合并;归属项目已不存在时标「项目已失联」)
- 启用口径分页各异:全局页按用户层;项目详情按该项目实际生效层级(本地 > 项目 > 用户)合并,并注明启用/禁用判定来自哪一层——只装给某项目的插件,在该项目详情显示启用、其他地方如实显示未启用
- 点行展开内含组件:skills(命名空间名)、subagents、hooks(事件摘要)、MCP servers;安装目录已被清理时标注"无法读取",列表行保留
- 有效启用插件的内含 skills 同时以「插件名:skill 名」条目出现在 Skills 分栏,带「插件」徽标、只读不可装卸,与磁盘同名 skill 并存互不遮蔽
- Codex 组为探测式:本机存在 Codex 插件缓存才显示,仅列名称/来源/版本(多版本缓存标注数量)

## 边界与不做
- 只读:不提供插件的安装、卸载、启停
- Codex 插件的启用状态与内含组件不展示(语义未接入,不给不确定的信号)
- hooks 只展示事件摘要,不展示命令内容
