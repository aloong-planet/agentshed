# UI language

> Related decisions: ADR-0035 (the language set), ADR-0013 (scope boundary)

## Overview

Non-Chinese speakers can use this product too: the UI switches between Chinese and English, chosen
automatically from the system's preferred language on first launch, and lockable to one language by
hand at any time. Switching takes effect immediately across all UI text, failure notices, date and
number formats, and the application menu.

## Capabilities

- The settings dimension (the settings entry at the foot of the rail) opens with "Language" as its first section, above appearance
- Three choices for the UI language: **follow system** (default), 简体中文 and English
- Each option is written in its own language with the English name alongside — so you can find your
  own language even when the current UI is in one you cannot read
- With "follow system" selected, both the option itself and the collapsed selector show which
  language it currently resolves to
- The system's preferred languages are matched **as a priority list**: if the system's first choice
  is not supported, the next is tried, and English is used if none are supported
- Choosing a specific language locks it: whatever the system language does afterwards no longer
  affects the UI; "follow system" can be selected again at any time
- A switch takes effect across the whole UI immediately, with no save and no restart; the sidebar
  hover tooltips and the **application menu** change with it
- The application menu follows the language chosen **inside the app**, not the system language; its
  entries into the app are "Settings" (⌘,), "Check for Updates…" and, in the Edit menu, "Search
  Sessions…" (⌘⇧F), alongside the standard platform items
- The **first frame** at startup is already in the correct language — there is no flash of a default
  language first
- The language choice is persisted and survives a restart
- The selector is fully keyboard-operable: focus it and press ↓ or Enter to open, arrow keys cycle
  through the three options, Enter selects, Esc cancels
- Relative times (today / yesterday / N days ago), dates and weekdays, number grouping and byte sizes
  all follow the current language; unit symbols (KB / MB / ms) are universal and are not translated
- Counts agree grammatically with the language: "1 session" and "2 sessions" in English, "0 sessions"
  included; in Chinese a count keeps the word that says what it counts
- Failure notices appear in the current UI language (a session that will not open, a turn that cannot
  be fetched, a failed skill install or uninstall, a link that will not open, a preference that will
  not save) — **every** failure notice is wired up, with no Chinese left behind

## Boundaries and non-goals

- All UI text is available in Chinese and English; agent-generated content is the exception (see below)
- No other language is offered: a system that prefers neither Chinese nor English — French, Japanese
  and so on — gets English. No right-to-left layout is provided
- Regional variants are not distinguished: a system language with a region or script matches on its
  base language, so Traditional Chinese shows Simplified Chinese and British English shows English
- Agent-generated content — sessions, memories, artifacts — is shown as written and is not
  translated; only the surrounding UI changes with the language
- The application name stays Agentshed
- Nothing is written to the agent configuration
