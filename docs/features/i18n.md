# 界面语言

> 关联决策: ADR-0013(语言集与范围边界)

## 概述

非中文用户也能用这个产品:界面可以在六种语言之间切换,首次启动时按系统偏好语言自动选定,也可以随时手动锁定某一种。切换即时生效,覆盖全部界面文字、失败提示、日期与数字格式,以及应用菜单。

## 能力

- 设置维(rail ⚙️)首个分节即「语言」,置于外观之前
- 界面语言七选一:**跟随系统**(默认)、简体中文、English、Français、Español、Русский、日本語
- 每个选项以该语言自身的文字书写,并附英文名——即便当前界面是看不懂的语言,也能认出自己的母语
- 选「跟随系统」时,选项内与收起后的选择器上都会显示它当前解析成了哪种语言
- 系统偏好语言按**优先级列表**匹配:系统首选语言不在支持范围内时,继续看下一个;全都不支持时用英文
- 选定某种具体语言后即锁定,系统语言此后怎么变都不再影响界面;可随时选回「跟随系统」
- 切换后立即对整个界面生效,无需保存或重启;侧边栏悬停提示与**应用菜单**一并改变
- 应用菜单跟随**app 内**选定的语言,而不是系统语言;菜单里有「设置」(⌘,)与「全局刷新」(⌘R)两个键盘入口
- 启动时**首帧**即为正确语言,不会先闪一下默认语言再跳变
- 语言选择持久化,重启后保留
- 选择器可纯键盘操作:聚焦后 ↓ 或回车展开、上下键在七项间循环、回车选定、Esc 取消
- 相对时间(今天/昨天/N 天前)、日期与星期、数字分组、字节量都按当前语言呈现;单位符号(KB / MB / ms)各语言通用,不翻译
- 操作失败时的提示按当前界面语言显示(如会话打不开、某一轮取不回来、skill 装卸失败、链接打不开、偏好保存失败)——**所有**失败提示都已接入,不留中文残留

## 边界与不做

- 界面文字已全部六语化;agent 生成的内容除外(见下条)
- 不支持阿拉伯语,也不提供从右到左的界面布局
- 不区分地区变体(没有单独的繁体中文、英式英语、巴西葡语等);带地区的系统语言按主语言匹配
- 会话、记忆、产物等 agent 生成的内容按原文显示,不翻译——只有界面外壳随语言变化
- 应用名保持 Agentshed 不变
- 不写入 Claude / Codex 配置
