# Skills 查看

## 概述
在全局 Agents · Skills 与项目详情 · Skills 中,可折叠展开磁盘 skill 包内文件并点开阅读正文。不做跨侧内容 diff。

## 能力
- 磁盘 skill 行内常显**文件数与大小**;**点行折叠/展开**包内文件表(每文件行数、大小、修改日期),展开区平铺不缩进
- 多侧存在时,展开区内切换侧查看对应包
- **点文件**开抽屉读正文;Markdown 默认预览(frontmatter 键值分行),可切原文;非 md 仅原文
- 深度过深时提示改造 skill,不列深层文件
- 项目详情:**同侧同名只展示项目级**;仅全局有的仍列出
- 插件来源 skill(命名空间条目)与磁盘 skill 同权可展开预览(行内统计/文件表/抽屉;仍无装卸)
- 装卸按钮与折叠/预览互不抢

## 边界与不做
- 列表行不展示 description(skill 说明看 SKILL.md 预览)
- 不提供跨 agent 侧机器 diff
- 不编辑/写回 skill
- 非文本文件不列出
