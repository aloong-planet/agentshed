# Application icon — approved visual study

Question: how should the application identify itself, and how should development differ?

The user approved the two standalone reactor images on 2026-09-14 and asked to apply them to the app.
The core uses the same soft illumination as the perimeter, with an even radial gradient. Production
is icy cyan; development is yellow throughout, with no corner indicator. These raster mockups are the
approved appearance, rather than a new HTML recreation of it.

![Production](approved-production.png)

![Development](approved-development.png)

The previews contain a painted checkerboard, not an alpha channel. That exterior is presentation
background, not part of the approved application silhouette; application assets need transparent
exteriors. Keep the casing, supports and luminous artwork when preparing the final images.
