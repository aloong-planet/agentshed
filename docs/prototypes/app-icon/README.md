# Application icon — approved visual study

Question: how should the application identify itself, and how should development differ?

The user approved the revised standalone reactor images on 2026-09-14 and asked to replace the
previous application artwork. The casing is evenly deep black without overhead illumination or a
top-to-bottom gradient. Upper support bends have subdued highlights matching the lower supports.
The core uses the same soft illumination as the perimeter, with an even radial gradient. Production
is icy cyan; development is yellow throughout, with no corner indicator. These raster mockups are the
approved appearance, rather than a new HTML recreation of it.

![Production](approved-production.png)

![Development](approved-development.png)

The production preview contains a painted exterior checkerboard; the development preview already
has an alpha channel. The checkerboard is presentation background, not part of the approved
application silhouette. Application assets have transparent exteriors; preparation preserves the
casing, supports and luminous artwork.
