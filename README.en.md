# Agentshed

[简体中文](README.md) · **English** · [Français](README.fr.md) · [Español](README.es.md) · [Русский](README.ru.md) · [日本語](README.ja.md)

Your coding agents’ tool shed: a full view of Claude Code and Codex across your projects — which skills / plugins / MCP each project has, how many tokens it burned, which documents it accumulated; and install / uninstall skills from the global library into any project.

An Electron desktop app. macOS first, Windows to follow. Under development.
