# Agentshed

[简体中文](README.md) · **English**

Your coding agents’ tool shed: a full view of Claude Code, Codex and Grok across your projects — which skills / plugins / MCP each project has, how many tokens it burned, which documents it accumulated; and install / uninstall skills from the global library into any project.

An Electron desktop app. macOS first, Windows to follow. Under development.
